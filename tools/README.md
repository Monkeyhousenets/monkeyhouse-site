# tools/

## yt-swipe-speed.user.js

Userscript for YouTube in a mobile browser: swipe **right** on the video to speed
up by 0.25x, swipe **left** to slow down. The current speed flashes on screen.
The chosen speed is remembered for the next video.

Install (Android):
1. Install Firefox for Android, then the Violentmonkey add-on from addons.mozilla.org.
2. Open the raw URL of this file in Firefox and tap **Confirm installation**.
3. Open m.youtube.com in Firefox and swipe on a playing video.

Tweakable constants (step size, min/max speed, swipe distance, remember-speed) are at
the top of the script.
